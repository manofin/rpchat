## 제품/IA 요약

- 좌측 고정 내비: 홈/활동/만들기/상점/가이드/최근 대화. 홈은 추천 캐릭터·세계관·태그 중심의 탐색 화면, 만들기는 캐릭터 제작 화면으로 이어진다. 활동·홈·만들기는 별도 탭에서 잠깐 확인 후 talk 탭을 보존했다.
- talk은 큰 세로형 아트와 우측 대화가 병렬인 2-pane 구조다. 우측 카드에 캐릭터 이미지, 대화, 미니 링크 포켓이 함께 놓인다.
- 포켓의 4개 탭(NOTI/STAT/TASK/NPC)은 짧은 라벨과 색상으로 즉시 접근한다. 카드마다 스냅샷 버튼이 반복 노출된다.
- 하단 입력 바에 모델 선택(`Donald 2`에서 시작, 중간에 `Breeze`로 전환), 메모리, 사진 추가, 액션(*) 및 생성/추천 아이콘이 모여 있다.
- 설정은 우측 드로어다. 대화방 이름/앨범/선택 모델/페르소나/유저 노트/맞춤 채팅방/목소리/북마크/캡처/공유/재답변/이어서 진행을 한 곳에 모은다.
- 사진 추가는 UI만 확인했으며 파일 선택·업로드는 하지 않았다. 상단 아트 앨범 썸네일과 입력기의 사진 추가가 별도 경로로 보인다.

## 턴 루프 체감

- 추천답변 생성 시 3개의 한국어 후보가 카드로 나타나고, 후보를 누르면 즉시 입력·전송된다. 후보에는 편집 아이콘도 붙어 있어 그대로 쓰거나 수정할 수 있다.
- 자유 입력은 텍스트를 입력하고 Enter/전송 버튼으로 보낸다. 응답 중에는 점 3개 로딩이 보이고, 응답 후 텍스트 카드와 새 이미지가 갱신된다.
- 응답을 기다리는 동안 입력창이 비활성에 가까운 상태가 되어 중복 전송을 줄인다. 다만 이미지 생성까지 포함돼 체감 대기 시간이 텍스트-only보다 길다.
- `*` 아이콘은 액션 문법을 입력창에 삽입했고, 마법봉/생성 아이콘은 추천답변 후보를 띄웠다. 추천과 자유 입력의 전환 비용이 낮다.
- 2-pane 아트는 장면 전환의 보상감이 크지만, 긴 대화에서는 텍스트보다 이미지가 화면을 많이 차지해 최신 발화 위치를 찾는 비용이 커진다.
- 9턴 동안 나디아/야나 등 이름과 앞선 맥락이 이어졌고, 짧은 질문에도 캐릭터의 행동·이미지가 함께 진행됐다. 그러나 긴 문맥에서 핵심 상태가 화면에 상시 고정되지는 않는다.

## NOTI/STAT/TASK/NPC가 주는 밀도

- **NOTI**: 알림 제목/시각/발화 요약을 작은 포켓에 압축한다. 시간 흐름과 최근 사건을 훑기 좋지만, 문장이 작고 스크롤 영역이 좁다.
- **STAT**: 사용자 상태(이름, 준비 상태, 외양/특징 등)를 간단한 라벨-값으로 보여준다. 수치형 RPG 스탯이라기보다는 현재 플레이어 카드에 가깝다.
- **TASK**: `QUEST LOG` 아래 목표/감정성 항목이 비어 있거나 대시로 보였다. 비어 있음도 상태로 보여주지만, 목표를 직접 만들거나 완료하는 UX는 이 탐색에서 확인되지 않았다.
- **NPC**: 소셜 링크 형태로 나디아(관계/호감 수치 및 태그), 설명 텍스트, 내부 스크롤을 보여준다. 캐릭터 목록과 관계 상태를 한 카드에서 확인할 수 있어 세계가 조밀하게 느껴진다.
- 네 패널은 본문을 가리지 않고 포켓 안에서 교체된다. 일상 대화의 몰입을 깨지 않으면서 정보 밀도를 올리는 좋은 패턴이다. 반대로 포켓 크기가 작아 상세 설명·접근성·모바일 확대에는 한계가 있다.
- 카드별 스냅샷은 눈에 잘 띄지만, 실제 실행 시 “윙과 깃털이 부족해요 / 충전” 안내가 나왔다. 핵심 기록 UX가 재화 게이트에 걸릴 수 있다.

## 메모리·페르소나·스냅샷

- 메모리 드로어에 `자동요약`과 `캐릭터 상태` 탭이 있다. 자동요약은 사용 토글, 날짜/시각, 장소 칩, 전체 서사 요약 카드, 편집 아이콘, 요약 명령어 기본을 노출한다.
- 캐릭터 상태 탭은 처음 꺼져 있었고, 켜자 황지명/나디아/야나를 `안심/무심` 같은 상태와 함께 행 목록으로 보여줬다. 행별 드롭다운과 삭제 아이콘이 있다. 상태 메모리의 on/off가 명확한 점은 좋지만, 켜면 무엇이 저장·전송되는지 한 줄 설명이 더 필요하다.
- 기본 대화 페르소나는 황지명(성별, 키, 특징 등을 텍스트로 입력)으로 관리된다. 이름/성별 라디오/정보 텍스트 영역, 글자 수(97/5,000), 저장 버튼이 있었다. “첫 1,000자까지만 반영” 안내가 보인다.
- 모델은 첫 화면에서 `Donald 2`로 확인했고, 모델 선택 드로어에서 비용/설명/즐겨찾기 모델을 비교한 뒤 중간에 `Breeze`로 전환했다. 전환 완료 토스트와 입력 바의 모델명 갱신을 확인했다. 즉, 페르소나(사용자 프로필)와 생성 모델(응답 엔진)이 별도 개념으로 노출된다.
- 스냅샷은 카드 우측에 반복 노출되며, 탐색 시 무료 잔여 재화가 없어 충전 안내만 확인했다. 무료 북마크/텍스트 핀과 유료 이미지 스냅샷을 분리하는 것이 rpchat에 유리해 보인다.

- 결제·충전·프라이빗 파일 업로드·API 스크래핑은 범위 밖이다.
- 게임식 수치/관계/퀘스트는 선택적 모듈로 제안하며, 모든 RP에 강제하지 않는다.
