## 읽는 순서 제안

1. `CLAUDE.md` — 특히 「Architecture」와 「Conventions」. 생성 경로가 **1:1**과
   **파티 비트** 둘로 갈라져 있고 서로 건드리면 안 된다는 점이 이 코드베이스의 핵심 제약이다.
2. `RP-Chat-PRD.md` — 무엇을 의도적으로 **안** 만들었는지(자동 요약, 임베딩, 충돌 해소)가
   기능 누락이 아니라 결정 사항임을 알 수 있다.
3. `party-beat-rp-review-spec.md` — 파티 비트 파이프라인 전체.
4. 나머지는 필요할 때.

- 이 사본들은 시간이 지나면 원본과 어긋난다. 작업 지시나 판단 근거로 쓰지 말 것.
